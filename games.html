Games

"Hangman" and seven small "Python" games: the "mini-projects" of the "Coursera" on-line class "Introduction to Interactive Programming in Python". They run in the browser on "CodeSkulptor".

How to play the "Python" games
  1. Click play on CodeSkulptor: the game opens in a new tab, already loaded.
  2. Just click on the "run" upper left button on "CodeSkulptor" to start playing.
  3. That's all: you do not need to read or change the code.
We highly recommend using "Chrome". Some games need the keyboard (see the labels below).
