Welcome to the personal homepages of Aristotelis Metsinis. Click on the left or top menu links, or on the links below, to see, use and discover:

  • curriculum vitae - the curriculum vitae of Aristotelis Metsinis, as a "PDF" document...
  • projects - MSc. projects, on-line class projects and small web tools:
    • Cellular Structure of Mobile Networks - an article on the cellular structure of mobile networks, published in the "Mobile Telephony and Telecommunications" magazine (February 1999) and part of the MSc. dissertation in "Telecommunication and Information Systems" (University of Essex)...
    • Erlang's Loss Formula - the theory behind the "Erlang B" formula, with an interactive loss probability calculator, and Statistical Analysis of Experimental Data - load X,Y experimental data to get descriptive statistics, a scatter plot and a least-squares regression model of up to 5th degree...
    • course work of on-line classes offered by "Coursera": a data analysis project in "R", "Python" mini-projects (including the games "Pong", "Blackjack" and "Asteroids"), an "Android" app and a "Ruby on Rails" web application...
    • tools for "SMS" / "SMPP" troubleshooting: the "SMS Message Analyser", which encodes a short message text into its hexadecimal data-stream representation (GSM or Unicode alphabet) and shows how a long SMS is split into parts with the proper "UDH" fields, and the new "SMPP Traffic Analyser", which loads a "pcap" / "pcapng" capture of "SMPP" over "TCP" and charts the request / response latency, the SMS rate, submitted (MT), received (MO) and delivery receipt statistics, errors and the "SMPP" window used, per connection and for all connections combined...
  • cheat sheets - quick reference cheat sheets with ready-to-use code templates: a "SQL" cheat sheet ("Oracle" "SQL" and "PL/SQL" script templates) and a "Perl" cheat sheet (under construction)...
  • hangman - a "hangman" word guessing game (in Greek)...
  • weather forecast, latest earthquakes and sky map - live widgets: a weather forecast, a map of the latest earthquakes (near real-time data from the U.S. Geological Survey, up to the past 30 days) and a sky map...
  • web links - links to miscellaneous web sites, such as programming tutorials and references...

The interactive tools (the "Erlang B" calculator, the statistical analysis, the "SMS" message analyser and the "SMPP" traffic analyser) run entirely in your browser: any data or file you open is processed locally and is never uploaded.
