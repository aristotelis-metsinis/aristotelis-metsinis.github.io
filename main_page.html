projects

MSc projects, online class projects and small web tools:

Cellular Structure of Mobile Networks – an article on the cellular structure of mobile networks, published in the Mobile Telephony and Telecommunications magazine (February 1999) and part of the MSc dissertation in Telecommunication and Information Systems (University of Essex).

Erlang’s Loss Formula – the theory behind the Erlang B formula, with an interactive loss probability calculator, and Statistical Analysis of Experimental Data – load X,Y experimental data to get descriptive statistics, a scatter plot and a least-squares regression model of up to 5th degree.

Coursework of online classes offered by Coursera: a data analysis project in R, Python mini-projects (including the games “Pong”, “Blackjack” and “Asteroids”), an Android app and a Ruby on Rails web application.

Tools for SMS / SMPP troubleshooting: the SMS Message Analyser, which encodes a short message text into its hexadecimal data-stream representation (GSM or Unicode alphabet) and shows how a long SMS is split into parts with the proper UDH fields, and the SMPP Traffic Analyser, which loads a pcap / pcapng capture of SMPP over TCP and charts the request / response latency, the SMS rate, submitted (MT), received (MO) and delivery receipt statistics, errors and the SMPP window used, per connection and for all connections combined.

cheat sheets

Quick reference cheat sheets with ready-to-use code templates: a SQL cheat sheet (Oracle SQL and PL/SQL script templates) and a Perl cheat sheet (under construction).

games

A hangman word guessing game (in Greek) and seven small Python games (RiceRocks, Blackjack, Memory, Pong, Stopwatch, Guess the Number, Rock-Paper-Scissors-Lizard-Spock) that can be played right in the browser – just click run on CodeSkulptor.

weather forecast, latest earthquakes and sky map

Live widgets: a weather forecast, a map of the latest earthquakes (near real-time data from the U.S. Geological Survey, up to the past 30 days) and a sky map.
